# 五張撲克牌遊戲

玩家可以在程式中體驗從設定資金、押注、發牌、換牌到最終結算的完整博弈流程。


## 核心功能

### 1. 完整牌局與賠率結算

* **精準判定**：支援一副 52 張撲克牌發牌、換牌，且精準辨識從「雜牌」到最高階「同花大順」等 10 種牌型。
  
* **獎金結算**：依牌型對應最高 250 倍賠率，自動結算當局獎金與淨利，並即時更新總資金。

### 2. 視覺回饋與沉浸體驗

* **狀態鎖定 (ReadOnly)**：開局後鎖死總資金，押注後鎖定金額，營造賭桌上「買定離手」的真實感。
  
* **千分位格式**：考慮到總資金面額可能巨大，因此自動套用逗號分隔（如 1,000,000），提升大面額數據的易讀性。

* **流程引導**：每個步驟皆附帶文字提示，引導使用者進行下一步操作。

* **色彩回饋**：結果標籤的背景顏色會依據玩家「贏錢、打平、虧損」三種狀態改變顏色為「紅、綠、灰」，強化使用者感受。

### 3. 防呆與極端處理

* **大數值處理 (long)**：金錢相關變數皆採用長整數型態，高支援千萬兆級別的運算，防止極端數值溢位。

* **輸入攔截**：自動過濾非數字、負數、零或「總資金不足」等無效操作。

* **彩蛋與機制**：
  
  - 破產重置：總資金歸零時觸發「破產借款」，自動重置 1,000,000 資金讓玩家敗部復活。
    
  - 財富巔峰：總資金達到 1,000 兆上限時，將觸發「賭神通關」隱藏彩蛋並結束遊戲。
    
  - 結算離場：一鍵總結自開局以來的總損益，並將遊戲重置回初始狀態。

### 4. 無滑鼠操作

* **自動聚焦**：啟動後自動聚焦，手不用離開鍵盤即可開始遊玩。
  
* **流暢切換**：全程支援 `Tab` 鍵切換欄位、`空白鍵`觸發按鈕及快速關閉警告視窗。


## 使用說明

1.  **設定初始總資金（開局前）**：
   
    * 在「總資金」欄位輸入初始本金（預設 1,000,000，最高支援至 1,000 兆）。
      
      > 若輸入格式非大於零之整數，將彈出錯誤視窗，關閉後會自動聚焦於總資金，方便玩家重新輸入。
      
      > 注意：總資金僅能在「首次押注前」修改，一旦按下押注，總資金將被鎖定至遊戲結束或玩家破產。

2.  **押注與發牌**：
    * 在「押注金額」欄位輸入本局欲下注之金額（預設為 1000）。
      
      > 若輸入格式非大於零之整數或大於總資金，將彈出錯誤視窗，關閉後會自動聚焦於押注金額，方便玩家重新輸入。

    * 點擊 `發牌` 按鈕後，將自動洗牌並發出 5 張底牌。

3.  **選擇換牌**：
   
    * 用滑鼠點擊想要「換掉」的撲克牌，被選中的牌將蓋上變回牌背圖案（再次點擊可取消）。
      
    * 確認完畢後，點擊 `換牌` 按鈕，系統將隨機替換成新的卡牌。
      
      > 注意：每局僅有一次換牌機會。

    * 點擊 `判斷牌型` 按鈕，會立即結算當局您的**牌型、贏得獎金與淨賺/虧損**，並將金額更新至總資金。
      
    * 結算完畢後，焦點會自動回到「押注金額」欄位，玩家可直接輸入數字進入下一局。

5.  **遊戲結束選項**：
   
    * **主動離場**：除非已經點擊 `押注` 進入牌局，否則隨時可點擊 `拿錢走人` 按鈕，查看自遊戲開始以來的總獲利或虧損，關閉提示視窗後會將遊戲重置為初始狀態。

    * **破產強制重置**：若當局結算後總資金歸零，系統將判定破產並跳出提示，隨後自動發放 1,000,000 救濟金讓玩家重新開局。

    * **達上限強制通關**：若總資金贏得超過系統極限（1,000 兆），將觸發「莊家賠不起」的隱藏通關彩蛋，並自動重置遊戲。

6.  **欄位跳轉與視窗關閉**：
   
    * 按 **`Tab 鍵** 就能在各個格子跟按鈕之間切換。
      
    * 支援以 `空白鍵` 快捷執行按鈕功能；遇到錯誤警告時，亦透過其快速關閉視窗，迅速返回原欄位修改。
